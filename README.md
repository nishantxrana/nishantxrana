## Things I've built

### [ToolDock](https://github.com/nishantxrana/ToolDock) · [live](https://tooldock.nishantxrana.com)

Browser-only toolkit for Azure DevOps engineers — **11** tools to compare, export, and import variable groups, App Service settings, and release variables. No backend, no database; PAT stays in the browser.

`React` · `TypeScript` · `Vite` · `ExcelJS`

### [ADO MCP Gateway](https://github.com/nishantxrana/AzureMcpGateway)

Multi-organization MCP gateway on Azure App Service for Microsoft Copilot Studio. One deployment serves many ADO orgs with per-alias API keys, Key Vault-backed secrets, and a default-deny tool policy so agents get read access without shared credentials or write-capable MCP surface.

`Node.js` · `TypeScript` · `Express` · `Azure Key Vault` · `App Service`

### [InsightOps](https://github.com/nishantxrana/InsightOps) · [live](https://stginsightops.azurewebsites.net/)

AI-assisted Azure DevOps monitoring platform used by a **120**-person engineering org — sprint, build, PR, and release visibility, encrypted org PATs, multi-provider AI diagnosis, and Google Chat alerts.

`Node.js` · `React` · `Express` · `MongoDB` · `Docker` · `Azure App Service`

### [Aclara](https://github.com/nishantxrana/Aclara) · [live](https://aclara.azurewebsites.net)

Interactive graph of Azure DevOps identities, group membership, and Git repository permissions — access tracing between users and repos, plus risk signals for over-privileged patterns.

`TypeScript` · `React` · `Express` · `Azure DevOps REST API`
